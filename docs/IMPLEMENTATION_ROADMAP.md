# Implementation roadmap

1. **Foundation:** native project, session engine, persistence, timer service, notifications and core screens.
2. **Verification:** Android Gradle build, Room/KSP generation, lint, emulator tests and real-device tests.
3. **Usage insights:** usage access permission, accurate daily app usage summaries and opt-in local reports.
4. **Blocking engine:** accessibility/usage-based enforcement with clear disclosure, allowlists/blocklists, schedules and emergency controls.
5. **Polish:** onboarding, accessibility, battery/OEM guidance, backup/export and release hardening.

Do not mark later phases complete until implemented and tested on supported Android versions.

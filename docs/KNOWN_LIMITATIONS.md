# Known limitations

- Android Gradle/Compose/Room code generation and emulator tests were not verified in the source environment at the time of this milestone.
- App blocking is not implemented in this foundation.
- Exact alarms, notifications and battery restrictions vary by Android version and OEM; user permission and device testing are required.
- Reboot recovery and foreground-service behaviour require real-device verification.
- No APK is included in this source milestone.

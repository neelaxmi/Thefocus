# Feature parity matrix

This is an independent implementation, not a claim of parity with any third-party app.

| Capability | This foundation |
|---|---|
| Focus timer and session history | Included |
| Strict session end cooldown | Core engine included |
| App-level blocking | Not implemented |
| Website / domain blocking | Not implemented |
| Schedules and per-app limits | Core policy model only; no Android enforcement UI |
| Usage access collection | Not implemented |
| Device/OEM reliability | Requires real-device validation |
